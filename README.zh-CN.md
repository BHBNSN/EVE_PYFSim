# EVE_PYFSim

[English](README.md)

**EVE_PYFSim** 是一个面向 **EVE Online** 的同人舰队战斗模拟器，核心基于 **pyfa/eos 装配数据** 与连续二维战术战场。项目主要用于 FC 练习、舰队建制测试、战术复盘，以及在投入真实游戏资产前进行快速推演。

> EVE_PYFSim 不是 CCP 官方产品，不是私服，也不是 EVE 客户端自动化工具。它是一个离线模拟器，定位于学习、战术训练和机制实验。

## 项目目标

EVE 的大规模舰队决策试错成本很高。EVE_PYFSim 希望提供一个低成本沙盘，用来回答这类问题：

- 这个建制能否抓住、按住并击杀对方建制？
- 初始距离、走位、集火、预集火顺序会如何改变战斗结果？
- 不同地图、信标、星门、泡泡和跃迁条件下，哪一边更占优？
- 电子战、后勤、无人机、舰载机、炸弹、泡泡和跃迁会如何影响舰队对抗？

项目关注的是 **FC 视角的决策循环**：舰队配置、小队指挥、目标点名、机动、弹药选择和战后复盘。

## 功能概览

### 核心模拟

- 连续二维空间战斗，包含移动、惯性、加速、接近/环绕、阵型跟随和距离控制。
- 确定性 Tick 仿真循环，便于重复练习、调试和复盘。
- 尽可能通过 pyfa/eos 解析舰船、模块和装配属性。
- 支持锁定、锁定时间、最大锁定距离、传感器属性、ECM 限制、电容消耗和模块周期。
- 支持炮台、导弹、投射物、炸弹、智能炸弹、远程维修、指挥脉冲和电子战模拟。
- 按护盾、装甲、结构三层 HP 结算伤害，并应用对应抗性。
- 支持跃迁、星门移动、星门隐身、跃迁扰断、拦截泡泡以及泡泡交互逻辑。

### 舰队与建制工具

- 支持从游戏或 pyfa 导出的 EFT 风格配装文本导入。
- 舰队库可保存和复用舰队配置。
- 基于小队的指挥模型，接近 EVE 中 FC 的操作习惯。
- 支持集火和预集火目标队列。
- 支持舰队范围内弹药切换与装填行为。
- 支持舰船在小队之间分配。
- 支持不同飞行员素养等级，用于模拟纪律性和执行力差异。

### 无人机、舰载机与部署物

- 支持无人机舱解析、带宽限制、最大活动无人机数量、发射/召回/攻击控制，以及基础电子战无人机效果。
- 支持舰载机舱解析、舰载机管数与槽位限制、舰载机中队发射/召回、目标分配和手动技能激活。
- 支持炸弹、导弹、通用投射物、智能炸弹拦截，以及泡泡/投射物伤害交互。

### 界面、局域网和复盘

- 基于 PySide6 的战术界面，支持战场平移和缩放。
- 支持可排序、可筛选的总览表格。
- 舰船状态窗口可查看模块、计时器、锁定、电容、HP、无人机和舰载机状态。
- 本地单人模式用于练习和调试。
- 局域网主机/客户端模式，支持双人 FC 对抗。
- 内置 Replay 与 Battle Report 基础设施，便于战后回放与分析。
- 支持简体中文界面翻译。

## 模拟精度说明

项目目标是做到 **足够接近原版机制以服务战术练习**，同时明确标注仍然属于近似模拟的部分。

| 模块 | 当前实现方式 |
| --- | --- |
| 配装 | 基于 pyfa/eos 的装配数据，并在模拟器侧进行运行时投射效果处理。 |
| Tick | 本地确定性 Tick 循环，不是 Tranquility 服务器实现。 |
| 空间 | 连续二维战场，使用简化的 grid / 星系抽象。 |
| 炮台与导弹 | 基于公式的模拟，包含投射物飞行和伤害结算，但不是完整服务端克隆。 |
| 无人机与舰载机 | 已具备发射、召回、目标、技能和限制等战术模型，部分原版边界细节仍在完善。 |
| 跃迁与泡泡 | 可模拟跃迁命令、星门移动、跃迁扰断和泡泡，但不保证覆盖所有原版服务端边界情况。 |
| Dogma | 尽可能使用 pyfa 数据，但尚未完整复刻 EVE Dogma 属性系统。 |

已知未完整覆盖的内容包括：完整 Dogma 修饰链、脑插、增效剂、热损、Crimewatch、统合部行为、市场、工业、主权、Upwell 结构计时器、无人机/舰载机全部边界情况，以及完整 PvE NPC 行为。

## 运行要求

- Windows 是当前主要测试平台。
- Python 3.13。
- PySide6 与 numpy。
- 本地 pyfa 源码/数据目录。当前模拟器数据清单面向 **pyfa v2.66.4**。

Linux 和 macOS 上非平台相关部分可能可以运行，但暂时不是主要发布目标。

## 安装指南

### 1. 克隆仓库

```bash
git clone https://github.com/BHBNSN/EVE_PYFSim.git
cd EVE_PYFSim
```

### 2. 创建虚拟环境

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 准备 pyfa

EVE_PYFSim 需要 pyfa/eos 数据来解析舰船、模块、弹药、无人机、舰载机和装配属性。

推荐目录结构：

```text
EVE_PYFSim/
├── main.py
├── eve_sim/
├── Pyfa-master/
│   ├── eos/
│   ├── service/
│   └── eve.db
└── requirements.txt
```

也可以通过 `PYFA_SOURCE_DIR` 指定 pyfa 目录：

```bat
set PYFA_SOURCE_DIR=C:\path\to\Pyfa-master
```

PowerShell：

```powershell
$env:PYFA_SOURCE_DIR = "C:\path\to\Pyfa-master"
```

## 快速开始

运行启动器：

```bash
python main.py
```

然后选择战斗模式：

| 模式 | 说明 |
| --- | --- |
| Local / 本地 | 单人练习和本地模拟。 |
| Host LAN / 主机 | 作为蓝方指挥官创建局域网对局。 |
| Join LAN / 加入 | 作为红方指挥官加入局域网对局。 |

基本流程：

1. 选择战斗模式。
2. 配置蓝方和红方舰队。
3. 导入或编辑 EFT 风格配装。
4. 校验舰队配置。
5. 开始战斗，在战术地图上指挥小队。
6. 通过舰船状态、总览、Replay 和 Battle Report 复盘。

## 操作说明

### 鼠标操作

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 选择己方小队或敌方目标。 |
| 双击空地 | 移动当前选中小队。 |
| 双击敌舰 | 接近或持续追击目标。 |
| 右键 | 打开上下文指令菜单。 |
| 右键点击舰船 | 显示舰船相关命令，例如集火、预集火或跃迁。 |
| 右键点击信标/星门/地图对象 | 显示可用的移动或跃迁命令。 |
| 中键拖拽 | 平移战术地图。 |
| 鼠标滚轮 | 缩放地图。 |

### 界面命令

| 命令 | 功能 |
| --- | --- |
| 小队选择器 | 切换当前活动小队。 |
| 队长速度限制 | 限制小队队长速度，便于协同机动。 |
| 推进模块开关 | 开启或关闭推进模块，用于控制战术走位。 |
| 清除集火 | 清空当前集火命令。 |
| 武器/弹药选择 | 为符合条件的舰船切换弹药。 |
| 分配舰船 | 将选中舰船移动到其他小队。 |
| 跃迁命令 | 命令当前小队跃迁到合法舰船、信标、星门或地图对象。 |
| 舰载机技能按钮 | 手动激活可用舰载机中队技能。 |

## 仓库结构

```text
eve_sim/
├── agents.py                 # 指挥官与舰船级决策 Agent
├── config.py                 # 引擎与界面配置

├── gui/                      # PySide6 界面、战术画布、对话框、表格
├── maps/                     # 地图/星系定义与加载
├── replay/                   # Replay 记录、增量快照、播放支持
├── scenario/                 # 场景模型、加载器与校验器
├── systems/                  # 战斗、移动、锁定、电子战、后勤、部署物
├── battle_report/            # 战报模型与服务
├── simulation_engine.py      # 主仿真循环
└── world.py                  # WorldState 与实体容器
```
